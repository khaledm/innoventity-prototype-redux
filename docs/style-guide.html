Visual Style Guide

Design tokens, components, and patterns for the Innoventity Angular SPA.

Angular 19 Angular Material 19.2 SCSS MDC-based Components

Design Tokens

All tokens are CSS custom properties defined in :root and consumed throughout the application.

Tokens are grouped into Brand, Semantic, Text, Surface, Border, Elevation, Spacing, Radius, and Transition families. Use these instead of raw values to ensure consistency. 

/* Example usage */
.my-element {
  color: var(--text-high);
  background: var(--surface-input-bg);
  border-color: var(--border-default);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-card);
  padding: var(--sp-4) var(--sp-6);
  transition: box-shadow var(--transition-fast);
}

Responsive Breakpoints

Two breakpoints defined consistently across component SCSS files.

Name Breakpoint Applies to Key changes
Tablet / Narrow max-width: 768px Innovations list, detail, sidebar Grid → single column; reduced margins; DL stack to 1-col; font-size reductions
Mobile max-width: 600px Login screen Reduced card padding (2rem / 1.5rem); border-radius 16px → 12px

Motion & Transitions

Single timing function used throughout: 0.2s ease. Applied to hover lift, shadow expansion, and opacity fades.

Interaction States

Button hover lift

transform: translateY(-1px);
box-shadow: var(--shadow-btn-hover);
transition: all 0.2s ease;

Card hover lift

Sample card
Hover me
transform: translateY(-2px);
transition: box-shadow 0.2s ease,
            transform 0.2s ease;

Token

/* Single transition token */
--transition-fast: 0.2s ease;

/* Used on */
button:hover   → box-shadow + transform
card:hover     → box-shadow + transform
input:focus    → border-color + background-color
form-field hover → border-color
